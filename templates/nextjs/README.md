# Next.js Template

Pre-configured template for Next.js projects with AI agent support.

## Files Included

- `opencode.json` - OpenCode configuration
- `.opencode/` - Agent and prompt configurations
- `package.json` - Dependencies

## Setup

```bash
# Copy template to your project
cp -r templates/nextjs/* /path/to/your-project/

# Install dependencies
cd /path/to/your-project/
npm install
```

## Features

- App Router configuration
- TypeScript support
- Tailwind CSS setup
- ESLint configuration
- AI agent integration

## Customization

1. Update `package.json` with your project name
2. Modify `.opencode/agents/` for custom agents
3. Add prompts to `.opencode/prompts/`
4. Configure routing in `opencode.json`

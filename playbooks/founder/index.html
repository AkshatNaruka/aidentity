Founder / Startup builder AI Agent Setup Playbook

What is the Founder / Startup builder AI Agent Playbook? The Founder / Startup builder AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to end-to-end startup building: product specs, shipping mvps, pricing, launch, ai seo, and pitch decks. It bundles 9 verified skills (Individual) or 12 skills + 4 runtime safety hooks (Enterprise), 2 coding rules, and 4 specialist subagents in one command.

Last updated: 2026-11-16 · Author: Akshat Naruka · Aliases: founder, ceo, cofounder, indie-hacker, startup, solopreneur, builder · Download playbook.md

Step 1 — Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup founder --profile individual
$ npx aidentity setup founder --profile enterprise

Frequently Asked Questions — Founder / Startup builder AI Setup

How do I set up Claude Code or Cursor for a founder / startup builder?

Run npx aidentity setup founder --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise founder / startup builder setup?

The Individual profile installs 9 core skills and essential secret/command safety hooks. The Enterprise profile installs 12 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Founder / Startup builder playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

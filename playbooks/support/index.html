Customer support AI Agent Setup Playbook

What is the Customer support AI Agent Playbook? The Customer support AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to tickets, escalation, help-centre content and customer research. It bundles 10 verified skills (Individual) or 14 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 3 specialist subagents in one command.

Last updated: 2026-11-23 · Author: Akshat Naruka · Aliases: support, customer-support, customer-success, csm, helpdesk · Download playbook.md

Step 1: Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup support --profile individual
$ npx aidentity setup support --profile enterprise

Frequently Asked Questions: Customer support AI Setup

How do I set up Claude Code or Cursor for a customer support?

Run npx aidentity setup support --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise customer support setup?

The Individual profile installs 10 core skills and essential secret/command safety hooks. The Enterprise profile installs 14 skills, adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening, plus format-on-save and test-on-stop hooks.

Are all skills in the Customer support playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

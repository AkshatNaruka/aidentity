Product designer AI Agent Setup Playbook

What is the Product designer AI Agent Playbook? The Product designer AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to ui direction, design systems, frontend implementation, accessibility. It bundles 18 verified skills (Individual) or 22 skills + 4 runtime safety hooks (Enterprise), 2 coding rules, and 2 specialist subagents in one command.

Last updated: 2026-11-17 · Author: Akshat Naruka · Aliases: designer, product-designer, ui-designer, ux-designer, design, ui-ux · Download playbook.md

Step 1 — Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup designer --profile individual
$ npx aidentity setup designer --profile enterprise

Set up my AI agent environment for the **Product designer** role using the **Individual** profile.

## 1. One-Command Automated Setup (Preferred)
If you have shell access in this workspace, run:
```bash
npx aidentity setup designer --profile individual --agent claude
```

## 2. Security & Provenance Gate (Mandatory)
Before installing or loading any skill, rule, or hook:
1. Verify against `https://akshatnaruka.github.io/aidentity/security.json` (or local `registry/security.json`) that `verified === true` and `risk_level === "safe"`.
2. Never install any skill where `distributable === false`, `content_url === null`, or `status !== "stable"`.
3. State the upstream author, SPDX license, and SHA-256 verification status before installing.
4. **Individual Guardrails**: Enable `block-dangerous.js` and `scan-secrets.js` to prevent accidental destructive commands or credential leaks.

Frequently Asked Questions — Product designer AI Setup

How do I set up Claude Code or Cursor for a product designer?

Run npx aidentity setup designer --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise product designer setup?

The Individual profile installs 18 core skills and essential secret/command safety hooks. The Enterprise profile installs 22 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Product designer playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

What is the Quant researcher AI Agent Playbook? The Quant researcher AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to backtesting, signals, risk, position sizing, fixed income and execution. It bundles 12 verified skills (Individual) or 16 skills + 4 runtime safety hooks (Enterprise), 1 coding rules, and 3 specialist subagents in one command.

Frequently Asked Questions: Quant researcher AI Setup

How do I set up Claude Code or Cursor for a quant researcher?

Run npx aidentity setup quant-researcher --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise quant researcher setup?

The Individual profile installs 12 core skills and essential secret/command safety hooks. The Enterprise profile installs 16 skills, adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening, plus format-on-save and test-on-stop hooks.

Are all skills in the Quant researcher playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

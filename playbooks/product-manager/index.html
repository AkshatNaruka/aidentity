Product manager AI Agent Setup Playbook

What is the Product manager AI Agent Playbook? The Product manager AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to specs, discovery, prioritisation, stakeholder updates, sprint planning. It bundles 13 verified skills (Individual) or 17 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 3 specialist subagents in one command.

Last updated: 2026-11-17 · Author: Akshat Naruka · Aliases: product-manager, pm, product, product-owner, po · Download playbook.md

Step 1 — Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup product-manager --profile individual
$ npx aidentity setup product-manager --profile enterprise

How do I set up Claude Code or Cursor for a product manager?

What is the difference between the Individual and Enterprise product manager setup?

The Individual profile installs 13 core skills and essential secret/command safety hooks. The Enterprise profile installs 17 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Product manager playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

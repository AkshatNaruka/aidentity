# Growth marketer AI Agent Setup Playbook (Individual & Enterprise)

**Definition:** The **Growth marketer AI Agent Playbook** configures any coding agent (Claude Code, Cursor, Codex, Gemini CLI, OpenCode, or GitHub Copilot) for acquisition, ads, cro, analytics, email, launch and retention. It installs 13 SHA-256 security-verified skills in the Individual profile and 17 skills plus 4 runtime guardrails in the Enterprise profile.

## Quick Commands

```bash
# Individual setup (13 verified skills)
npx aidentity setup marketer --profile individual

# Enterprise setup (17 verified skills + supply-chain & security hooks)
npx aidentity setup marketer --profile enterprise
```

## Individual vs. Enterprise Comparison

| Component | Individual Profile | Enterprise Profile |
|---|---|---|
| Verified Skills | 13 core skills | 17 skills (+4 security/audit skills) |
| Coding Rules | 0 rule files | 0 rule files |
| Subagents | 3 subagents | 4 subagents |

What is the Growth marketer AI Agent Playbook? The Growth marketer AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to acquisition, ads, cro, analytics, email, launch and retention. It bundles 13 verified skills (Individual) or 17 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 3 specialist subagents in one command.

Frequently Asked Questions — Growth marketer AI Setup

How do I set up Claude Code or Cursor for a growth marketer?

Run npx aidentity setup marketer --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise growth marketer setup?

The Individual profile installs 13 core skills and essential secret/command safety hooks. The Enterprise profile installs 17 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Growth marketer playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

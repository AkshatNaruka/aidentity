AI Agent Setup Playbooks by Role

What is an AI agent setup playbook? An AI agent setup playbook is a deterministic, step-by-step configuration blueprint that installs verified SKILL.md files, language coding rules, specialist subagents, slash commands, and safety hooks into Claude Code, Cursor, Codex, Gemini CLI, OpenCode, or GitHub Copilot for a specific job role. Every Aidentity playbook is available in two profiles — Individual (fast solo workflow) and Enterprise (supply-chain audits, secret scanning, and test-on-stop guardrails) — with 100% of skills SHA-256 verified in security.json.

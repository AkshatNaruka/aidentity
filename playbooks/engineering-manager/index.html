Engineering manager AI Agent Setup Playbook

What is the Engineering manager AI Agent Playbook? The Engineering manager AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to sprint delivery, capacity, retrospectives, hiring and people ops. It bundles 13 verified skills (Individual) or 16 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 3 specialist subagents in one command.

Last updated: 2026-11-17 · Author: Akshat Naruka · Aliases: engineering-manager, em, tech-lead, team-lead, vp-engineering · Download playbook.md

Step 1 — Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup engineering-manager --profile individual
$ npx aidentity setup engineering-manager --profile enterprise

Frequently Asked Questions — Engineering manager AI Setup

How do I set up Claude Code or Cursor for a engineering manager?

Run npx aidentity setup engineering-manager --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise engineering manager setup?

The Individual profile installs 13 core skills and essential secret/command safety hooks. The Enterprise profile installs 16 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Engineering manager playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

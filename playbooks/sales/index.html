Sales AI Agent Setup Playbook

What is the Sales AI Agent Playbook? The Sales AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to prospecting, outreach, pipeline, crm hygiene and deal support. It bundles 12 verified skills (Individual) or 16 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 2 specialist subagents in one command.

Last updated: 2026-11-17 · Author: Akshat Naruka · Aliases: sales, ae, sdr, account-executive, revops, bd · Download playbook.md

Step 1: Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup sales --profile individual
$ npx aidentity setup sales --profile enterprise

Frequently Asked Questions: Sales AI Setup

How do I set up Claude Code or Cursor for a sales?

Run npx aidentity setup sales --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise sales setup?

The Individual profile installs 12 core skills and essential secret/command safety hooks. The Enterprise profile installs 16 skills, adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening, plus format-on-save and test-on-stop hooks.

Are all skills in the Sales playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

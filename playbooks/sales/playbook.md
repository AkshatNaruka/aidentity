# Sales AI Agent Setup Playbook (Individual & Enterprise)

**Definition:** The **Sales AI Agent Playbook** configures any coding agent (Claude Code, Cursor, Codex, Gemini CLI, OpenCode, or GitHub Copilot) for prospecting, outreach, pipeline, crm hygiene and deal support. It installs 12 SHA-256 security-verified skills in the Individual profile and 16 skills plus 4 runtime guardrails in the Enterprise profile.

## Quick Commands

```bash
# Individual setup (12 verified skills)
npx aidentity setup sales --profile individual

# Enterprise setup (16 verified skills + supply-chain & security hooks)
npx aidentity setup sales --profile enterprise
```

## Individual vs. Enterprise Comparison

| Component | Individual Profile | Enterprise Profile |
|---|---|---|
| Verified Skills | 12 core skills | 16 skills (+4 security/audit skills) |
| Coding Rules | 0 rule files | 0 rule files |
| Subagents | 2 subagents | 3 subagents |
| Slash Commands | 1 commands | 2 commands |
| Safety Hooks | hooks/scan-secrets.js, hooks/block-dangerous.js | hooks/scan-secrets.js, hooks/block-dangerous.js, hooks/format-on-save.js, hooks/test-on-stop.js |

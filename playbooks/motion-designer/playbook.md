# Motion designer AI Agent Setup Playbook (Individual & Enterprise)

**Definition:** The **Motion designer AI Agent Playbook** configures any coding agent (Claude Code, Cursor, Codex, Gemini CLI, OpenCode, or GitHub Copilot) for motion graphics, video composition, easing, rendering and review. It installs 11 SHA-256 security-verified skills in the Individual profile and 15 skills plus 4 runtime guardrails in the Enterprise profile.

## Quick Commands

```bash
# Individual setup (11 verified skills)
npx aidentity setup motion-designer --profile individual

# Enterprise setup (15 verified skills + supply-chain & security hooks)
npx aidentity setup motion-designer --profile enterprise
```

## Individual vs. Enterprise Comparison

| Component | Individual Profile | Enterprise Profile |
|---|---|---|
| Verified Skills | 11 core skills | 15 skills (+4 security/audit skills) |
| Coding Rules | 1 rule files | 1 rule files |
| Subagents | 2 subagents | 3 subagents |
| Slash Commands | 1 commands | 2 commands |
| Safety Hooks | hooks/scan-secrets.js, hooks/block-dangerous.js | hooks/scan-secrets.js, hooks/block-dangerous.js, hooks/format-on-save.js, hooks/test-on-stop.js |

Software engineer AI Agent Setup Playbook

What is the Software engineer AI Agent Playbook? The Software engineer AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to day-to-day coding: planning, implementation, review, tests, debugging. It bundles 8 verified skills (Individual) or 11 skills + 4 runtime safety hooks (Enterprise), 3 coding rules, and 3 specialist subagents in one command.

Last updated: 2026-11-16 · Author: Akshat Naruka · Aliases: software-engineer, developer, engineer, dev, swe, fullstack, backend, frontend · Download playbook.md

Step 1 — Run the One-Command Setup

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

$ npx aidentity setup software-engineer --profile individual
$ npx aidentity setup software-engineer --profile enterprise

Frequently Asked Questions — Software engineer AI Setup

How do I set up Claude Code or Cursor for a software engineer?

Run npx aidentity setup software-engineer --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise software engineer setup?

The Individual profile installs 8 core skills and essential secret/command safety hooks. The Enterprise profile installs 11 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Software engineer playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

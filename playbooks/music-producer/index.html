Music producer AI Agent Setup Playbook

What is the Music producer AI Agent Playbook? The Music producer AI Agent Playbook is a complete, security-verified configuration for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and GitHub Copilot tailored to lyrics, song structure, mastering, album concepts and release assets. It bundles 11 verified skills (Individual) or 15 skills + 4 runtime safety hooks (Enterprise), 0 coding rules, and 2 specialist subagents in one command.

Last updated: 2026-11-17 · Author: Akshat Naruka · Aliases: music-producer, music, songwriter, lyricist, audio-producer · Download playbook.md

Choose Individual for solo work and fast iteration, or Enterprise for team governance, supply-chain security audits, and automated pre-commit/stop hooks:

Frequently Asked Questions — Music producer AI Setup

How do I set up Claude Code or Cursor for a music producer?

Run npx aidentity setup music-producer --profile individual --agent claude (or --agent cursor). The CLI verifies SHA-256 digests against security.json and writes the skills, coding rules, subagents, and hooks to your agent directory.

What is the difference between the Individual and Enterprise music producer setup?

The Individual profile installs 11 core skills and essential secret/command safety hooks. The Enterprise profile installs 15 skills — adding Trail of Bits supply-chain risk auditing, agentic actions auditing, and security hardening — plus format-on-save and test-on-stop hooks.

Are all skills in the Music producer playbook security-verified?

Yes. Every skill in this playbook is scanned by scripts/scan-skills-security.js for hidden Unicode, hardcoded credentials, destructive commands, and prompt injection, with SHA-256 hashes published at security.json.

Defense in Depth

3. How Aidentity Verifies Skill Security (7-Gate Static Analysis)

Unverified SKILL.md files from random repositories can contain invisible Trojan-Source Unicode, prompt injection directives that leak .env secrets, or destructive shell operations. Every skill in Aidentity (2499 files across 533 skills) is scanned on every commit by scripts/scan-skills-security.js:

Gate 01

Hidden & Trojan Unicode

Rejects zero-width spaces (U+200B–U+200D), byte-order marks, and bidirectional override characters (U+202A–U+202E, U+2066–U+2069).

Gate 02

Hardcoded Secrets & Keys

Scans for live AWS, GitHub, OpenAI, Anthropic, Slack, Stripe, and PEM private keys across every instruction file.

Gate 03

Destructive Shell Patterns

Blocks rm -rf /, fork bombs, raw disk writes (dd, mkfs), and root permission wipes.

Gate 04

Prompt Injection & Exfiltration

Detects instructions attempting to override system guardrails, exfiltrate environment variables, or establish reverse shells.

Gate 05

Untrusted Remote Scripts

Flags curl | sh and wget | bash patterns that fetch and execute arbitrary unverified code from the network.

Gate 06

Symlink & Binary Hygiene

Rejects symlinks pointing outside the skill directory and unexpected compiled binary blobs.

Gate 07

Deterministic SHA-256 Digest

Computes canonical SHA-256 hash across every file in the skill directory, published in security.json.

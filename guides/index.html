3. How Aidentity Verifies Skill Security (7-Gate Static Analysis)

Unverified SKILL.md files from random repositories can contain invisible Trojan-Source Unicode, prompt injection instructions that exfiltrate .env secrets, or destructive shell commands. Every skill in Aidentity (2492 files across 526 skills) is scanned on every commit by scripts/scan-skills-security.js:

  1. Gate 1 — Hidden & Trojan-Source Unicode: Rejects zero-width spaces (U+200B–U+200D), BOMs, and bidirectional override characters (U+202A–U+202E, U+2066–U+2069).
  2. Gate 2 — Hardcoded Secrets & Keys: Scans for live AWS, GitHub, OpenAI, Anthropic, Slack, Stripe, and PEM private keys.
  3. Gate 3 — Destructive Shell Patterns: Blocks rm -rf /, fork bombs, raw disk writes (dd, mkfs), and root permission wipes.
  4. Gate 4 — Prompt Injection & Exfiltration: Detects instructions attempting to override system guardrails, exfiltrate environment variables, or open reverse shells.
  5. Gate 5 — Untrusted Remote Script Execution: Flags curl | sh and wget | bash patterns.
  6. Gate 6 — Symlink & Binary Hygiene: Rejects symlinks escaping the skill directory and unexpected compiled binaries.
  7. Gate 7 — Deterministic SHA-256 Digest: Computes a canonical SHA-256 hash over every file in the skill folder and publishes it in security.json.

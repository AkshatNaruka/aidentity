Why an index, and not another list

01

Links rot. Quietly.

Most skill collections are a markdown file that was accurate once. Every source here is re-checked weekly by CI, and the date is printed on the page. If a source dies, it gets flagged, not ignored.

02

Licenses are invisible until they aren't.

Each entry states its license and author. Content we can't redistribute is indexed but not hosted — clearly marked. That is the difference between a useful index and a takedown notice.

03

Every agent invents its own folder.

One skill ID installs into six different agents. You shouldn't have to learn each tool's directory layout, or re-copy files when you switch editors.

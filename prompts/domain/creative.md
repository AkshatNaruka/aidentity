# Creative Prompts

## Content Creation

```markdown
Create engaging content about:
[Topic]

Style: [Professional/Casual/Humorous]
Audience: [Target audience]
Length: [Word count]
Tone: [Formal/Informal]
```

## Storytelling

```markdown
Write a compelling story about:
[Theme/Character/Situation]

Include:
- Engaging opening
- Character development
- Conflict and resolution
- Memorable ending
```

## Brainstorming

```markdown
Brainstorm ideas for:
[Purpose/Goal]

Generate:
- 10 creative ideas
- Different approaches
- Unconventional solutions
- Implementation considerations
```

## Naming

```markdown
Generate names for:
[Product/Feature/Project]

Criteria:
- Memorable
- Easy to pronounce
- Relevant to purpose
- Domain available (if applicable)
```

## Visual Description

```markdown
Describe a visual concept for:
[Purpose]

Include:
- Color palette
- Layout structure
- Key elements
- Mood and style
- Accessibility considerations
```

## Brand Voice

```markdown
Define brand voice for:
[Company/Product]

Characteristics:
- Personality traits
- Tone guidelines
- Do's and don'ts
- Example phrases
```

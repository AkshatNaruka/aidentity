# Writing Prompts

## Technical Documentation

```markdown
Write technical documentation for:
[Feature/API/Component description]

Include:
- Overview
- Prerequisites
- Step-by-step guide
- Code examples
- Troubleshooting
- FAQ
```

## Blog Post

```markdown
Write a blog post about:
[Topic]

Requirements:
- Engaging title
- Hook introduction
- Well-structured sections
- Practical examples
- Clear conclusions
- Call to action
```

## Email Draft

```markdown
Write a professional email about:
[Purpose]

Include:
- Clear subject line
- Appropriate greeting
- Concise body
- Call to action
- Professional closing
```

## README File

```markdown
Write a comprehensive README for:
[Project description]

Include:
- Project overview
- Features
- Installation
- Usage examples
- Configuration
- Contributing guidelines
- License
```

## API Documentation

```markdown
Document this API endpoint:
[Endpoint details]

Include:
- Description
- Method
- URL
- Parameters
- Request/Response examples
- Error codes
- Rate limiting
```

## User Guide

```markdown
Write a user guide for:
[Feature/Application]

Include:
- Introduction
- Getting started
- Step-by-step instructions
- Screenshots/visuals
- Tips and tricks
- Troubleshooting
```

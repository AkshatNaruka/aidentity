# Research Prompts

## Technology Research

```markdown
Research [technology/framework/tool]:

Provide:
- Overview and purpose
- Key features
- Pros and cons
- Use cases
- Alternatives
- Learning resources
- Community size
```

## Best Practices Research

```markdown
Research best practices for:
[Topic/Domain]

Include:
- Industry standards
- Expert recommendations
- Common pitfalls
- Case studies
- Tools and resources
```

## Competitor Analysis

```markdown
Analyze competitors for:
[Your product/service]

Compare:
- Features
- Pricing
- Target audience
- Strengths/weaknesses
- Market positioning
```

## Market Research

```markdown
Conduct market research for:
[Product/Service idea]

Include:
- Target market size
- Customer segments
- Demand indicators
- Competition
- Trends
- Entry barriers
```

## Literature Review

```markdown
Review literature on:
[Research topic]

Synthesize:
- Key findings
- Methodologies
- Gaps in research
- Future directions
- Practical implications
```

## Trend Analysis

```markdown
Analyze trends in:
[Industry/Technology]

Identify:
- Current trends
- Emerging technologies
- Future predictions
- Impact on business
- Opportunities
```

# Analysis Prompts

## Data Analysis

```markdown
Analyze this data:
[Paste data here]

Provide:
- Key insights
- Trends and patterns
- Anomalies
- Recommendations
- Visualizations suggestions
```

## Document Analysis

```markdown
Analyze this document:
[Paste document here]

Extract:
- Main points
- Key arguments
- Supporting evidence
- Conclusions
- Action items
```

## Code Analysis

```markdown
Analyze this codebase:
[Paste code or describe project]

Evaluate:
- Architecture quality
- Code maintainability
- Test coverage
- Documentation status
- Security posture
```

## Market Analysis

```markdown
Analyze the market for:
[Product/Service description]

Include:
- Target audience
- Competitor analysis
- Market size
- Trends
- Opportunities and threats
```

## Risk Assessment

```markdown
Assess risks for:
[Project/Decision description]

Identify:
- Technical risks
- Business risks
- Resource risks
- Mitigation strategies
```

## Root Cause Analysis

```markdown
Perform root cause analysis for:
[Problem description]

Use:
- 5 Whys technique
- Fishbone diagram approach
- Timeline analysis
- Contributing factors
```

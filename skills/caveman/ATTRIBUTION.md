## Notes

These are output-compression skills: they change how the agent writes, not what
it can do. The base `caveman` skill is self-contained and needs no install.

**Runtime warning:** the upstream repository also ships a proxy, Go engine, and
MCP server. **None of that is imported here.** These skills only contain the
prompt surfaces. Do not install the upstream runtime unless you have reviewed it.

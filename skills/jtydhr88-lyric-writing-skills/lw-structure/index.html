lw-structure

The structural layer of a lyric (词的结构层) - what each section is for and what it must not say, which song form to pick, where the title lands and how often it comes back, and how line counts, line lengths and rhyme placement make a section feel finished or still owing something. Covers verse / pre-chorus / chorus / bridge / refrain functions, central versus developmental sections, AABA and verse-chorus and verse-refrain forms, the five structural parameters (balance, pace, flow, closure, closure type), the five hook-placement strategies, and the deliberate asymmetry that keeps a lyric from sounding machine-made. Use when laying out sections before writing a line, when a chorus does not feel like an arrival, when a bridge sounds like one more verse, when every section came out the same length, when deciding where the title goes, or when LYR-LINT check 3, 4 or 10 fails. 段落结构、曲式、副歌、bridge、hook、标题位置、句式、不对称、段落功能、AABA。

词的结构（Lyric Structure）

结构管的不是"写什么"，是"什么时候说、说完了没有"。

> Pattison 开宗明义：好结构替代不了好写作，它只是好写作的一部分；

> 结构要处理的是时机与位置（manage timing and placement）。

> —— Pattison《Lyric Form》p0004

1. 总纲：一首词只有两个动词

> 移动（MOVING）与停止（STOPPING）。

> 每一个歌词段落的工作，都可以从这两者之一去看。

> —— Pattison《Lyric Form》p0052

由此派生出本 skill 的全部内容，一句话版本：

> 平衡（对称）让运动停下，不平衡（不对称）把词往前推。

> —— Pattison《Lyric Form》p0063

1.1 中心段落与发展段落

Pattison 把所有段落分成两类（《Lyric Form》p0052）：

类装什么结构任务
CENTRAL SECTION（中心段落）CENTRAL IDEA——这首词的主信息停下来。到这里想法被完成
DEVELOPMENTAL SECTION（发展段落）引向或发展中心思想的想法往前推，一直推到中心段落

★ 词里的一切要么朝中心段落移动，要么从它离开。（《Lyric Form》p0052）

这一条直接决定了你该把力气花在哪：

发展段落写得再漂亮，如果它自己就停住了，中心段落就不会有"到了"的感觉。

自检动作：把段落名一列写下来，在每个后面写 →（推） 或 ■（停）。

如果出现两个连着的 ■，或者从头到尾全是 →，结构有问题。

1.2 四个球

Pattison 把作词比作杂耍：写任何一段词，你在同时抛四个球（《Lyric Form》p0007–p0008）——

  1. 我要用几句？（How many phrases）
  2. 每句多长？（How long will each phrase be）
  3. 每句用什么节奏？（What rhythms）
  4. 韵脚怎么排？（How should I arrange the rhymes）

★ 这四个就是构成一个段落的全部变量（《Lyric Form》p0063）。

§5 逐个讲怎么用它们。

⚠ 注意第四个球在本库属于共管：

韵脚选什么字归 lw-rhyme，韵脚落在第几句归这里。

1.3 「句」是什么

Pattison 定义的 phrase：句子，或者句子里天然成立的片段（从句）；

词的句与旋律的乐句通常一一对应（《Lyric Form》p0008）。

> 「像一对恩爱夫妻，歌词短语和乐句应该匹配。让它们不同步通常会导致灾难。」

> —— Pattison《Lyric Form》p0010

★★ 这是先曲后词最容易翻车的地方：

一个完整意思被劈到两个乐句里，听起来会很怪并且把情感带走（《Lyric Form》p0010）。

失效条件：如果你的词是给已有旋律填的，

先用斜线标出你自己的语义断句，再和旋律的乐句边界对一遍——

两条线不重合的地方，改词不改曲。

★ 在 LYR-SPEC 里，prosody.sections[].syllables 的一个元素 = 词稿里的一行 = 一句。

分行不是排版，是指令。

2. 段落类型与功能

各段落类型的完整功能表（verse / pre-chorus / chorus / bridge 各自的任务、信息量递进、常见失败）见 [reference.md](reference.md)。

下面两条是 Stolpe 给"一段里面怎么排、段与段之间怎么推"的骨架，功能表是在它们上面长出来的。

2.1 ★ Toggling：一段之内，外部细节与内部细节交替

外部细节写主角周围正在发生什么，内部细节写主角心里或脑子里正在发生什么（p0006）。

一行可以两者兼有，抽象或比喻性的描述会把外部细节推向内部。

Toggling 就是把这两种细节交替排开，目的是四个（p0006）：段落权重得当、段与段有对比、体验更强、把最好的想法摆在该摆的位置。

书里的六行例子排成 E · E/I · I · E · E/I · I：前半建立的模式在后半重复，

音乐乐句开始和结束的位置，也是 Toggling 模式开始和结束的位置（p0006）。

★ 权力位置：段落最后一行天然担着总结整段的责任。把最后一行从外部改成内部，段落就有了闭合感（p0006）。

三种排错（p0006）：

排法后果
后半全是内部变成在告诉听众主角的感受，而不是让听众体验它
后半全是外部沉重，听众不知道这些景物跟主旨有什么关系
前半全是内部外部细节被推迟到段落中间才出现。书里的比喻是吃完牛排再撒盐

自检：给每一行标 E 或 I，看模式是不是断的，看最后一行是不是 I。

2.2 ★ Pyramiding：段与段之间，从特写推到全景

歌曲的想法从窄到宽、从拉近到拉远推进，像镜头，也像圣诞树的形状（p0008）：

层段落视野
顶主歌最窄
中预副歌稍宽
底副歌最宽
最低枝标题行最宽

每段的最后一行通常是内部细节，作用是拉远镜头，给前面的细节赋值（p0008）。

三种推错（p0008）：段尾重新聚焦到外部细节，细节就和主旨脱了关系；

段首视野太宽，段尾就没地方再拓；副歌比主歌更拉近，听众不信这是主旨。

第二主歌相对第一主歌要再拉远一档（p0008）：更偏内部、深化副歌的意义，

不一定绑在某个事件或时间框架里。有时它延续外部细节，是为了移到过去或未来，给下一次副歌重新着色。

> 这两条和 lw-song-intent §1.2 的类型表是配套的：

> 叙事型的第二主歌靠新事件推进，其余三类靠拉远镜头推进。拉远也是推进，不是复述。

3. 曲式

3.1 Song System：比"段落"更大的单位

> Song System = 一组在更大的运动循环里协同工作的段落。

> 它总是包含一个中心段落，通常还有一个或多个发展段落。

> —— Pattison《Lyric Form》p0056

  • verse / chorus / verse / chorus = 两个 Song System（《Lyric Form》p0056）
  • 每个 Song System 是一个循环，在中心段落之后关闭；

一旦一个系统走完，你必须开始新东西，或者把歌结束掉（《Lyric Form》p0056）

  • ⚠ 适用范围：段落种类不同（verse+chorus、verse+bridge+chorus）时最有用；

如果所有段落都一样、都装着中心思想，这个概念帮不上忙（《Lyric Form》p0056）

★ 这是排段落顺序时真正该数的东西：不是数了几段，是数了几个循环。

3.2 选形式的总原则

> 「Content dictates form.」（内容决定形式。）

> 只有合适的形式才能支撑并加强歌词的目的，交付你要的结果。

> —— Davis《Successful》p0032

★ 两家不矛盾：内容决定你要推还是要停（Davis），推停决定形式（Pattison）。

3.3 常见形式的性格（两家并排）
形式结构原理性格 / 适用
Verse/Refrain打油诗原则：陈述 A → 重述 A → 变奏 B → 回归 A（Pattison《Lyric Form》p0070）靠"建立大本营再离开"制造张力与解决；叙事型、话多的歌
AAA段落彼此独立，没有 bridge 也没有 chorus，每段常 16 小节（Davis《Successful》p0036–p0038）★ 最适合造角色、换时间框架、换场景；⚠ 旋律最容易变成单调的节奏引擎
AABA传统 32 小节 = 8/8/8/8，但小节数不必规整（Davis《Successful》p0040–p0041）★ 不间断地表达单一时刻的情感；几乎要求单一时间框架、一致视角、不变场景（Davis p0040）。bridge 把你带离大本营，回第三段 A 是"真正的返乡"（Pattison p0058）
ABAB / ABAC两个 16 小节段落连成（Davis《Successful》p0044）ABAC 的 C 段只听到一次，适合把词继续发展下去（Davis p0045–p0046）
Verse/ChorusCommon Meter（叙事诗节） 原则（Pattison《Lyric Form》p0072）主歌管展开、副歌管收拢；中心段落独立成段，重复起来最省力
Verse/Climb/Chorus在一个 Song System 内加一级不平衡（Pattison p0060；Davis 叫 climb，《Successful》p0054）副歌来得更"值"；★ climb 够长够对比时，这首歌就不需要 bridge（Davis p0054）
Verse/Chorus + Bridgebridge 插在两个完整 Song System 之后（Pattison p0059）此时每个 verse/chorus 系统相当于 AABA 里的一个 A；⚠ Davis 认为这里的 bridge 愉快但非必要（《Successful》p0052）

理由是避免重复带来的厌倦（《Lyric Form》p0075）。

每种形式的小节数、标题位置、变体（含 12 小节布鲁斯、通体作曲）见 reference.md §1。

3.4 A-B-A-B 的内部逻辑

Pattison 把四行的 A-B-A-B 拆成（《Lyric Form》p0073）：

陈述 A → 新陈述 B → 重述第 1 句的结构 A → 重述第 2 句的结构 B。

★ 这套"陈述—重述"的逻辑在句内、段内、段落之间是同一套——

这是本 skill 最省力的一个认识：你只需要学会一层，其余层照搬。

4. hook 与标题

4.1 在词里，hook 就是标题

语料实测：最抓耳那句在副歌段首 62%、段尾 22%、首尾都有 10%（国语非说唱 n=487；这一栏两模型盲判只有 59% 一致，当粗参照）；说唱段首 48%、首尾都有 22%（n=100）；粤语段首 56%（n=36）。

> 「在歌词里，"HOOK" 的意思（或者说应该是）就是"TITLE"。

> 它是中心思想的聚焦陈述。」

> —— Pattison《Lyric Form》p0062

⚠ 注意这与编曲里的用法不同：编曲说的 hook 指反复出现的音响事件。

词的 hook = 标题；曲的 hook = 那段动机。 两者可以互相加持，但不是一回事。

★ Davis 的定义更宽：

> **hook 是歌里抓住听众注意力、听一遍就留在记忆里的那部分。

> 通常歌曲的标题就是它的 hook。次一级的 hook 可以是器乐短句，或一段抓人的节奏律动。**

> —— Davis《Successful》p0055

★★ 怎么用这两个定义：

写词时用 Pattison 的窄定义（否则"hook"会变成一个没法执行的词）；

交接给编曲时用 Davis 的宽定义——器乐 hook 与律动 hook 归作曲编曲，但它们应当与词的 hook 落在同一个位置。

4.2 放哪：热点位

Pattison 列的 hook 落点（《Lyric Form》p0062）：

  • 平衡位（balancing position）
  • 欺骗位（deceptive position）
  • 意外位（unexpected position）
  • 副歌的第一句和／或最后一句

> 「开头和结尾。两个热点（HOT SPOTS）。」

> —— Pattison《Lyric Form》p0083

★★ 最该记住的一句：

> 「你放进热点位的任何想法都会变成你最重要的想法。你是靠把它放在那里，使它变重要的。」

> —— Pattison《Lyric Form》p0084

推论：别纠结"我最重要的意思是哪句"，先决定把哪句放在热点位。

⚠ verse/refrain 形式里的限制（《Lyric Form》p0083）：

通常 hook 要么在段首、要么在段尾，一般不两头都放——

两头都放意味着每段主歌都要用两次，通常太多了。

4.2b ★ 段首还是段尾：两家不一致

Pattison 把开头和结尾当成两个同等的热点（《Lyric Form》p0083）。

Davis 在 verse/chorus 这一种形式里给出了排序：

> 把标题放在副歌顶部，无疑创造最大的冲击力与持久力。

> 末行标题是较弱的选择：虽然也能出热门，但要求听众等太久才知道这歌讲什么，

> 常给人"默认演化出来的"而不是"设计出来的"印象，并且很少产生翻唱。

> —— Davis《Successful》p0051

★ 不冲突的读法——看形式：

形式标题位置依据
AAA每段开头或每段结尾，两者皆可Davis《Successful》p0037
AABAA 段开头或 A 段结尾，两者皆可Davis《Successful》p0041
ABAB / ABAC每个 AB／AC 的第一行或最后一行Davis《Successful》p0046
Verse/Chorus★ 优先副歌顶行Davis《Successful》p0051
Verse/Refrain段首或段尾，★ 一般不两头都放Pattison《Lyric Form》p0083

★★ 一条跨形式通用的补充（Davis《Successful》p0041）：

即使标题在开头，好工匠也会把最后一个段落塑造成让标题在歌曲结尾再响一次，

好让它留在听众记忆里。

标题本身够不够格（三条标准、多选病、"把标题留给标题"）见 reference.md §4。

4.3 出现几次

> 「你的 HOOK 应该在每个 Song System 里至少出现一次。通常这就够了。」

> —— Pattison《Lyric Form》p0086

★ "每个 Song System 一次"是下限，不是节拍器。

Pattison 同时指出直接重复简单但有效（《Lyric Form》p0086），

并且举了 hook 在副歌首尾各一次的例子（A SLOW HEALING HEART，《Lyric Form》p0083）。

★★ 重复的最好理由是结构需要（《Lyric Form》p0087）：

他举的例子里，段落正是靠最后那次重复才被补成平衡的——

这时候重复不是懒，是配平。

自检动作：把最后一次 hook 划掉，重数句数与重音数。

如果划掉之后段落反而平衡了，那次重复是多余的；如果划掉之后段落变瘸了，它是结构件。

4.4 让 hook 当主角的五个策略

Pattison 的五条（《Lyric Form》p0082、p0092）：

  1. 把 hook 放在段落的开头或结尾，也可以两头都放（限制见 §4.2）
  2. 让结构一路朝前，直到撞上 hook——中心段落里，节奏与韵脚一路推，落在 hook 上才点亮、平衡并关闭段落；发展段落里，用不平衡往前推，让下一段用 hook 开头（p0085）
  3. 重复 hook（见 §4.3）
  4. 用声音给 hook 打光（他叫 TARGETING）——★ 提前用 hook 里出现的元音把耳朵调准。他举 "I CAN'T FIGHT THIS FEELING ANY MORE"：三个 "ite" 音给 hook 里最重要的词 "feeling" 做铺垫（p0088）
  5. ★ 在别的战略位置使用 hook 的节奏——相当于作曲里的动机发展：陈述主题，然后在别处以不同方式再用它（加速、减速、倒置、保形改音）（p0089）

★★ 第 5 条附带一条工作顺序的硬要求：

> 「在开始写你的歌词之前，先知道你的 HOOK 的节奏。」

> —— Pattison《Lyric Form》p0089

两个理由（《Lyric Form》p0089）：

一是这是一种不惹人烦的重复主题的方式；二是它让主题成为整首作品的焦点。

附带好处：主歌的句长和节奏选择因此不再随意。

⚠ 第 4、5 条在中文里要换算：

元音铺垫对应韵母的提前出现，hook 的节奏对应那几个字的字数与停顿位置。

声调另算，归 lw-tone-check。

5. ★ 句式的稳定与不稳定

这是 Pattison 的核心，也是本 skill 最该写透的一节。

5.1 一个段落只有四个变量

（《Lyric Form》p0063）

  1. 句数（Number of phrases）
  2. 句长（Length of phrases）
  3. 每句的节奏（Rhythm of phrases）
  4. 韵式（Rhyme scheme）

★ 改一个段落的手感，只能从这四个里动手。 下面逐个讲。

5.2 变量一：句数 —— 奇偶决定"完了没有"

> 偶数句让结构感觉平衡；奇数句显得尴尬（awkward）。

> 不平衡段落创造"前进感"，平衡段落"停止运动"。

> —— Pattison《Lyric Form》p0011

平衡／不平衡的三个用途（《Lyric Form》p0011）：

★ 全文与例在 [reference-stability.md](reference-stability.md)。

5.3 变量二：句长 —— 控制速度，不是求快

> 像杂耍的人一样，目标不是变快，是控制速度。句长是最强的速度控制器之一。

> —— Pattison《Lyric Form》p0015

★ 全文与例在 [reference-stability.md](reference-stability.md)。

5.4 变量三：节奏 —— 数重音，不数总音节

> 判断一句长短的标准不是数音节总数，而是数重读音节的个数。

> —— Pattison《Lyric Form》p0029

PARADIGM 1：四重音句与三重音句交替 = Common Meter（共同格律）（《Lyric Form》p0029）。

次重音不改变模式，句首非重音的起拍（pickup）也不改变模式。

★ 它至今常见，因为它完美契合八小节乐句的各种细分：4/4 拍里，

四重音的第一句正好占两小节；**第四小节第三拍的休止用来区分第二句与第一句，

同时用这个休止定义四小节乐句**（p0030）。

★ 全文与例在 [reference-stability.md](reference-stability.md)。

6.0 ★ 先说预算：重复本身从来不是问题

本节讲不对称，但不对称不等于少重复。这两件事被混在一起，是本库产出过长、过满的根因。

也就是几乎没有重复。结构重复度按压缩率算，不受分行方式影响，是主指标。

两首叙事型商业歌的不同行占比最低（0.50、0.55）。越会讲故事的歌重复越多，

因为它把副歌整个交给了重复，主歌才有空间往前讲。

三条预算规则：

  1. 副歌逐字重复是所有类型的常态（→ lw-song-intent §1.2）。前两遍相同不是缺陷，那是听众记住 hook 的方式。

lw-ai-tell-audit 第 8 条抓的是各遍全同、末遍既没改一字也没加尾，不是"有重复"，也不是"全同"本身（语料 27% 的歌全同）。

  1. ★ 末段微变是可靠的默认，但不是唯一常态：语料里末遍副歌与首遍逐字相同的占近三成，改一两行的一成半，

其余差得更多，中位差 4 行，多半是末遍加了尾句或扩了一段，不是重写。所以两条路：照抄并改一到三个字，改的字落在热点位（段首或段尾）；

或照抄后加尾。本库作者的四首词全用前一手，整首的重量压在那几个字上。它是 asymmetry.chorus_variation 该填的东西，

整遍重写是少数，重写等于放弃了前两遍攒下的期待。

  1. 不同行占比超过 0.85，先怀疑预算没花（写了太多新内容），再怀疑对称。

这个数字只是粗筛，写进 asymmetry.repetition_budget 的是你打算让副歌重复几遍、主歌靠什么推进。

  1. ★ 副歌占全曲两成半到七成，中位近一半（非说唱 P10 0.26、中位 0.48、P90 0.68；说唱中位 0.34）。这是预算落地的那个数：三遍副歌各 8 行是 24 行，全曲就该在 36–60 行之间。

先定副歌几行几遍，再算主歌还剩几行。 副歌占比够了而结构重复度仍低，问题就在主歌：主歌之间也该有复用（同一句式换一个变量、预副歌两遍相同），

不是每段都从零写。

两条顺手的：非说唱首个副歌中位出现在全曲 22% 处（P90 36%），也就是两段主歌之内必须进副歌，第一段主歌加预副歌超过全曲三分之一就晚了；

有 Pre-Chorus 的歌只占 24%、有 Bridge 的 33%，这两段都不是默认配置，写之前先问要不要（→ §2、§3）。

末遍处理三分天下（无变 43／改字 25／加尾 21）与破题句分布见 [reference.md](reference.md) 末节。按年代看：四十年里歌变长、副歌占比变小、重复度变低，Bridge 从一成到三成，副歌全同与 Pre-Chorus 的比例没动（同文件末节）。

为什么会写多：不知道有预算 → 副歌也不敢重复 → 每段都要新内容 → 只能靠新事件 → 词又长又全是故事。

§6.1 之后讲的所有不对称，都是在预算花掉之后再做的事。

6.1 机制，不是偏好

每段字数一样、副歌三遍一模一样之所以像机器，理由在 Pattison 的体系里是可推的：

症状它在结构上意味着什么依据
每段句数相同且都是偶数每段都在自己那里闭合了，没有任何一段在往前推——整首词只有"停"没有"移动"平衡停止运动 / 不平衡产生前进感（《Lyric Form》p0011）
每句字数相同★ 速度恒定，你放弃了最强的速度控制器全等长 = PACE CONSTANT（《Lyric Form》p0016）
副歌各遍逐字相同、末遍既没改字也没加尾没有"意外闭合"、没有"惊喜的多出来那一句"、没有任何位置被点亮。★ 前两遍相同是常态（§6.0），问题只在末遍惊喜的额外短语给两行打聚光（《Lyric Form》p0013）
bridge 与主歌同构从第一句起就不该一样，同构等于没有 bridge《Lyric Form》p0064

★★ 反过来说也成立：破坏不是目的。

Pattison 的每一处不平衡都有指向——推进、聚光、或对比（《Lyric Form》p0011）。

LYR-SPEC 要求"每一处不对称都要说得出理由"，就是这个意思。

6.2 asymmetry 三项怎么填
字段填什么从哪来自检
short_line哪一行故意短§5.3：短句加速。★ 最好放在中心段落之前，让它把词推进副歌把这行补到和别的行一样长，念一遍。 如果听起来"更顺了但没劲了"，这行短得对
unrhymed哪一段故意不押§5.5：不押就没有解决点，系统保持开放问：这里的开放是我要的吗？ 如果这段本该收住（副歌），那就不是不对称，是漏了
chorus_variation副歌第三遍改了哪个词§2.7：末次副歌让贯穿物件最后变一次含义；§5.2 用途 3：在结尾加一句制造惊喜★ 改的那个词必须落在热点位（段首或段尾），否则听众不会注意到（《Lyric Form》p0083）

★ 三项至少填两项（LYR-LINT 第 4 条）。

只填一项时，最容易补的是 chorus_variation——它的代价最小、效果最直接。

6.3 不对称的落点优先级

同样是"弄不平衡"，落在不同位置价值差很多：

  1. 第二段主歌的结尾（最高价值）——加一句把它推进副歌（《Lyric Form》p0013）
  2. 末次副歌——改词或加句，让结尾不等于前两遍
  3. bridge 整段——它本来就该是全词最不平衡的一段（《Lyric Form》p0057）
  4. 第一段主歌（最低价值）——★ 这里应该规整，它要给全词定标准（《Lyric Form》p0053）

⚠ 常见误区：为了过 lint，把不对称全砸在第一段主歌上。

那会毁掉参照系，后面所有"破"都失去对象。

7. 与曲式对齐

7.1 段落 id 一一对应
LYR-SPEC 字段规则
prosody.sections[].id ＝ lyrics[].section★ 就是段落 id form[].id（C1、A2，不是 Chorus 这种名字），一一对应
form[].bars小节数是作曲编曲的决定；先词后曲时由本库按字数句式定（§7.2、§7.4）
form[].name段落名；先曲后词时照 meta.upstream.form 用，不改
prosody.sections[].syllables一个元素 = 词稿里的一行 = 一句
prosody.sections[].stress_positions§5.4：哪几个字踩强拍
prosody.sections[].peak_syllable★ 全段最高音落在哪个字

★ form[].id / form[].bars / form[].name 是与歌曲另一侧共享的字段：谁先做谁定，后做的一方只读；想改，写一条消息（lw-workflow §6.1、§6.2）。

7.2 结构决定小节数的两条换算
依据换算
Common Meter ↔ 八小节四重音的一句在 4/4 拍里正好两小节；四小节乐句靠第四小节第三拍的休止来定义（Pattison《Lyric Form》p0030）。★ 所以四句 common meter ≈ 八小节，这是最省事的对齐起点
句长 ↔ 音符密度非重读音节增加会挤占空间，要求更快更短的音符；减少则允许更长的音符或休止（《Lyric Form》p0028）。★ 所以同样的小节数，句子拉长就必然逼出十六分音符的旋律
7.3 refrain 不占 id

★ refrain 是主歌的最后一两句，不是独立段落（《Lyric Form》p0061）——

不要给它单独的 form[].id，否则编曲会把它当成一个独立段落去配器。

7.4 先词后曲：反向约束

先词后曲时，本 skill 的产出就是交给作曲编曲的东西：

给出去用途
各段句数与每句字数定 form[].bars
每段的五要素表（§5.6）告诉作曲编曲这一段是推还是停，对应编曲的能量走向
hook 的节奏（§4.4 第 5 条）★ 先定，再写别的——它会当成动机在别处复用

⚠ 先词后曲时词更容易写得整齐划一，因为没有外来约束——§6 的反对称要更用力。

8. 写完必过

  • [ ] 每个段落标了 →（推）还是 ■（停），没有连着两个 ■，也不是全是 →（§1.1）
  • [ ] 第一段主歌是全词最规整的一段，你说得出它的句数、每句几个字、韵式（§2.2）
  • [ ] 副歌是最平衡的一段，而且它"停"住了（§2.4）
  • [ ] ★ bridge 从第一句起就与主歌不一样（§2.5）
  • [ ] 过渡桥段比主歌短或比主歌急，不是主歌的续行（§2.3）
  • [ ] 数过 Song System 的个数，每个里面 hook 至少出现一次（§3.1、§4.3）
  • [ ] 标题落在热点位（段首／段尾／欺骗位／意外位）（§4.2）
  • [ ] ★ 动笔前就定了 hook 的节奏（§4.4）
  • [ ] 把每段每句的字数列成数字串看过一遍，不是一串相同的数（§5.3）
  • [ ] 每段填过五要素表（§5.6）
  • [ ] 被聚光灯打亮的位置上放的是你最想让人记住的话（§5.7）
  • [ ] asymmetry 至少填两项，且每一处都说得出理由（§6.2）
  • [ ] 不对称没有全砸在第一段主歌（§6.3）
  • [ ] 段落 id 与 form[].id 一一对应；refrain 没有单独占 id（§7.1、§7.3）

# AGENTS

Guidance for AI agents (OpenCode, Claude Code, Codex, Cursor, Copilot, Gemini CLI) working **on this repository**.

## What this repo is

Aidentity is a verified index of AI agent skills. The registry is the product:

- `registry/skills.json` — every skill: id, description, category, tags, status, source, license, install command
- `registry/sources.json` — provenance and redistribution rights per upstream
- `registry/pointers/` — metadata for sources we may index but not host
- `registry/verified.json` — last successful upstream check

One source of truth. The site, the CLI, and the docs all read it.

## Rules

1. **Never add skill content we cannot redistribute.** If the upstream license is absent, proprietary, or unclear, add a pointer entry only (`distributable: false`, `path: null`, `upstream.url` set).
2. **Never hand-edit generated files.** `registry/skills.json`, `registry/verified.json`, and `THIRD_PARTY_NOTICES.md` are generated by the scripts below.
3. **One skill per pull request.** Don't reformat unrelated records.
4. **Keep descriptions factual.** What it does and when to use it. No marketing language.
5. **Run the gate before claiming done.**

## Agent surface

- `search.json`, `llms.txt`, `llms-full.txt`, `agent.json` are generated into the site.
- `cli/mcp.js` is a zero-dependency MCP server: search, recommend, get, list bundles, install (dry-run by default).
- `cli/index.js recommend "<task>"` returns a bundle and ranked skills.
- Raw `SKILL.md` files are published at `/skills/<id>/SKILL.md`.
- Index-only entries (`distributable: false`) must never be presented as installable.

## Commands

```bash
node scripts/build-registry.js        # regenerate registry/skills.json from skills/**
node scripts/build-registry.js --check # verify the registry is current
node scripts/check-licenses.js        # legal gate: fails on redistribution violations
node scripts/verify-sources.js        # re-check every upstream (writes verified.json)
node scripts/generate-notices.js      # regenerate THIRD_PARTY_NOTICES.md
node site/build.js                    # build the static site into site/dist
node site/serve.js                    # preview at http://localhost:4173
node cli/mcp.js                       # MCP server (stdio)
node cli/index.js recommend "<task>"  # bundle + ranked skills
```

## Adding a skill

1. Confirm the upstream license permits redistribution (MIT, Apache-2.0, CC0, BSD).
2. Place the skill under `skills/<source-key>/<skill-name>/` with the upstream `LICENSE` present at `skills/<source-key>/LICENSE`.
3. Add the source to `registry/sources.json` if new.
4. Run `node scripts/build-registry.js && node scripts/check-licenses.js`.
5. Open a PR using the submit-a-skill template.

If the license does not permit redistribution, add a JSON file under `registry/pointers/` instead. See `registry/pointers/anthropic-official.json` for the shape.

## Writing style

Direct, specific, no hype. Say what a thing does and what it costs. Avoid "revolutionary", "seamless", "supercharge". Numbers over adjectives.

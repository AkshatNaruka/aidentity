# Rules

Short, stack-specific conventions an agent can follow without loading a full skill.
Extracted from [affaan-m/everything-claude-code](https://github.com/affaan-m/everything-claude-code) (MIT, commit `25278e7`).

| File | Applies to |
|---|---|
| `python/coding-style.md` | Python naming, typing, structure |
| `python/fastapi.md` | FastAPI routes, dependencies, errors |
| `typescript/coding-style.md` | TypeScript types, modules, async |
| `react-native/coding-style.md` | RN components, hooks, styling |
| `golang/coding-style.md` | Go packages, errors, concurrency |

Use these as a baseline when no framework-specific skill applies. They are rules, not tutorials: short enough to paste into `AGENTS.md` or a system prompt.

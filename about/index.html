Manifesto & Verification

An Index, with Receipts

There are thousands of AI agent skills. They live in dozens of repositories, in conflicting directory conventions, under unstated licenses. Finding one is easy. Knowing whether it's safe to run, who wrote it, and what you're allowed to do with it is not. Aidentity is the verifiable registry.

Registry Architecture

Four Principles of Aidentity

01 · Safety First

Deterministic Security

Every skill is scanned across 7 static analysis gates for Trojan Unicode, credentials, prompt injections, and destructive commands. SHA-256 digests in security.json.

02 · Attribution

Upstream Respect

Aidentity is an index, never a fork. We preserve upstream authors, source links, and original licenses. Where licenses prohibit re-hosting, we link directly without mirroring.

03 · Normalization

Cross-Agent Portability

One unified registry maps seamlessly across Claude Code, Cursor, OpenAI Codex, Gemini CLI, OpenCode, and Copilot. One CLI installs to the exact right directory.

04 · Fast & Machine-Ready

Zero-Bloat Performance

Built with zero runtime JavaScript dependencies. 100% static HTML/CSS, machine-readable JSON endpoints, and full llms.txt support for autonomous RAG agents.

Security & Integrity

The 7-Gate Security Scanner

Every skill in the registry (2499 files across 533 entries) is scanned by scripts/scan-skills-security.js and recorded in security.json with a deterministic SHA-256 digest. The scanner strictly blocks:

Gate 01

Trojan & BiDi Unicode

Rejects zero-width spaces (U+200B), byte-order marks, and bidirectional direction overrides.

Gate 02

Hardcoded Secrets

Rejects live AWS, GitHub, OpenAI, Anthropic, Slack tokens, and private PEM keys.

Gate 03

Destructive Commands

Blocks rm -rf /, fork bombs, disk formatters (mkfs), and raw disk writes.

Gate 04

Prompt Injections

Detects instructions attempting to exfiltrate env vars or bypass system safety guardrails.

Transparency

Licensing Policy

Every skill in the registry strictly observes its upstream license:

  • Redistributable (MIT, Apache-2.0, CC BY): Mirrored with preserved upstream license notices.
  • Non-Redistributable (Proprietary, Index-Only): Pointers with name, description, author, and direct link only. Never copied.
  • Repository Code: Aidentity tooling is MIT. Registry metadata is CC0. Original writing is CC BY 4.0.

Frequently Asked Questions

Everything You Need to Know

What is Aidentity? ›
Aidentity is a verified, open-source registry of 533 AI agent skills and 21 role-based setups. Each entry records its source repository, author, license, SHA-256 security verification status, category, and automated verification date.
How do I set up my agent for my job role? ›
You can run npx aidentity setup <role> --profile individual (or enterprise), use the interactive 5-question wizard on our Setup page, or browse complete blueprints in the Playbooks directory.
Are the skills free to use? ›
Yes, 100% of the skills indexed are free. The majority are licensed under MIT or Apache-2.0. Trail of Bits skills are licensed under CC BY-SA 4.0. Upstream skills from Anthropic are indexed with direct reference links. Every page clearly states its specific license.
How do I install a skill into my coding agent? ›
Run npx aidentity add <id> --agent claude (or cursor, codex, gemini, opencode, copilot). The CLI automatically detects your active coding agent and writes files to the exact directory required.
How do you keep the index safe and updated? ›
CI rebuilds the registry on every commit, executes the 7-gate static analysis scanner, and computes deterministic SHA-256 hashes. A scheduled weekly workflow tests every upstream Git repository and writes fresh verification timestamps to registry/verified.json.
Can I contribute a new skill or repository? ›
Yes! Submitting a skill requires just one JSON entry and a GitHub pull request. CI automatically verifies schema conformity, license compliance, and security checks. Submissions are reviewed by maintainers within 24 hours.
